# Daily Focus - Минималистичный трекер задач

Элегантный и функциональный трекер задач, вдохновленный философией дизайна Джони Айва. Простота, ясность и удовольствие от использования.

## 🌟 Особенности

- **Минималистичный дизайн** - Чистый интерфейс без лишних элементов
- **4 категории задач** - Работа, Личное, Здоровье, Обучение
- **Визуализация прогресса** - Круговой индикатор выполнения задач
- **Статистика** - Отслеживание выполненных задач за день, неделю и дней подряд
- **История задач** - Просмотр выполненных задач за все время
- **Сохранение данных** - Автоматическое сохранение в localStorage
- **Адаптивный дизайн** - Отлично работает на всех устройствах
- **Плавные анимации** - Приятные глазу переходы и эффекты

## 🚀 Установка и запуск

### Вариант 1: GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы (index.html, styles.css, script.js)
3. Перейдите в Settings → Pages
4. В разделе Source выберите "Deploy from a branch"
5. Выберите ветку main и папку / (root)
6. Нажмите Save
7. Через несколько минут ваш трекер будет доступен по адресу:
   `https://[ваш-username].github.io/[название-репозитория]/`

### Вариант 2: Локальный запуск

1. Скачайте все файлы в одну папку
2. Откройте файл index.html в браузере
3. Готово! Трекер работает локально

### Вариант 3: Любой веб-сервер

Просто загрузите все файлы на ваш веб-сервер. Не требуется никаких дополнительных настроек или зависимостей.

## 💾 Сохранение данных

Трекер автоматически сохраняет все данные в localStorage браузера. Это означает:
- Данные сохраняются даже после закрытия браузера
- Каждое устройство хранит свои данные локально
- Не требуется регистрация или подключение к базе данных

## 🔄 Синхронизация между устройствами

Для полной синхронизации между устройствами вы можете:

1. **Использовать Firebase** (бесплатно):
   - Создайте проект на firebase.google.com
   - Добавьте Firebase SDK в index.html
   - Раскомментируйте код синхронизации в script.js

2. **Использовать GitHub API**:
   - Создайте GitHub Gist для хранения данных
   - Используйте GitHub API для чтения/записи

3. **Использовать собственный бэкенд**:
   - Создайте простой API для хранения данных
   - Обновите функцию syncData() в script.js

## 📱 Использование

1. **Добавление задач**: 
   - Выберите категорию
   - Введите текст задачи
   - Нажмите Enter или кнопку "+"

2. **Выполнение задач**:
   - Нажмите на круг слева от задачи
   - Задача будет отмечена как выполненная

3. **Удаление задач**:
   - Наведите на задачу
   - Нажмите на крестик справа

4. **Просмотр истории**:
   - Нажмите кнопку "История" внизу
   - Увидите все выполненные задачи по дням

## 🎨 Кастомизация

Вы можете легко изменить цветовую схему, отредактировав CSS-переменные в файле styles.css:

```css
:root {
    --primary-color: #007AFF;  /* Основной цвет */
    --secondary-color: #5856D6; /* Дополнительный цвет */
    --success-color: #34C759;  /* Цвет выполненных задач */
}
```
